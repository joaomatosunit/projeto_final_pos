# Projeto Final Pós Graduação
Projeto Final do curso de Pós Graduação Ciência de Dados e Inteligência Artificial\
Universidade Tiradentes (UNIT)

📌 Sobre o projeto\
Este repositório reúne os materiais, códigos-fonte, dados, experimentos e documentação desenvolvidos durante a elaboração do projeto final da pós-graduação.

🎯 Objetivos\
Aplicar conceitos e técnicas estudados durante a pós-graduação.\
Desenvolver uma solução baseada em Ciência de Dados e Inteligência Artificial.\
Organizar os dados e experimentos utilizados no projeto.\
Documentar a metodologia e os resultados obtidos.\
Disponibilizar os materiais produzidos para consulta e reprodução.
